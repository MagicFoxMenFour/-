# Единый Календарно-Постановочный План (КПП) для съёмочных групп кинолаборатории

Внедрение централизованного производственного календаря и интерактивного таймлайна сдачи пилотных серий для всех 5 действующих групп лаборатории с контролем дедлайнов, фаз (Препродакшн / Съёмки / Постпродакшн) и цеховых задач.

## User Review & Critical Decisions

> [!IMPORTANT]
> На основе ваших ответов зафиксированы следующие ключевые решения:
> 1. **Актёры**: 14 актёров остаются в общем резерве кинолаборатории в статусе свободного кастинга (не закрепляются жёстко за группами, группы приглашают их по мере готовности сценариев).
> 2. **Производственные задачи**: формируется **единый интерактивный КПП лаборатории** со сквозным графиком смен, этапов и дедлайнов для 5 групп.
> 3. **Экспорт**: дополнительная выгрузка списков не требуется, все данные отслеживаются в реальном времени внутри приложения.

- **Подтверждённое решение 1**: Единый таймлайн производства для всех 5 групп (Группа 1, Группа 2, Объединенная Группа 3, Группа 4, Команда Павливской Группа 5).
- **Подтверждённое решение 2**: Актёрский цех сохраняется на скамейке запасных в статусе готовности к пробам.

## 1. Overview & Core Concept

- **Что делает**: Добавляет в интерфейс куратора и личные кабинеты участников интерактивную вкладку **«Производственный КПП и График»**. В ней в наглядном календарно-линейном виде представлены 4 ключевых производственных этапа:
  1. *Литературный драфт и тритмент пилота* (Сценарный цех)
  2. *Режиссёрская экспликация, раскадровка и локейшн-скаутинг* (Режиссура + Операторский цех)
  3. *Кастинг актёров из резерва и вызывные листы* (Продюсерский цех)
  4. *Съёмочные смены и черновой монтаж (Assembly Cut)* (Монтаж + Звук)
- **Целевая аудитория**: Главный продюсер / Кураторы кинолаборатории, режиссёры и лидеры групп, участники цехов.
- **Ценность**: Исключает путаницу с дедлайнами, наглядно показывает текущую стадию каждой группы (в графике / задержка / готово к сдаче), автоматически синхронизируется через облачную базу Firestore.

## 2. User Experience & Visual Design

- **Пользовательский сценарий**:
  1. Куратор переходит во вкладку **«КПП и График»** в панели навигации модератора.
  2. Видит обзорную шкалу по всем 5 группам: цветные карточки групп с полосой прогресса готовности пилота (0–100%).
  3. Интерактивная матрица этапов: клик по этапу открывает ответственного участника, статус сдачи материала, ссылку на документ/диск и дедлайн.
  4. Куратор может в 1 клик скорректировать дедлайн этапа, перевести группу в следующую стадию (например, из *Pre-production* в *Production*) или отметить этап выполненным.
  5. В личном кабинете участника (Member Cabinet) автоматически подсвечивается актуальная задача его группы согласно общему КПП.

- **Визуальный стиль & интерфейс**:
  - Тёмная кинематографичная палитра (Zinc-900 / Zinc-950) с фирменными акцентными цветами групп (Amber, Emerald, Sky, Cyan, Rose).
  - Моноширинные цифры (`tabular-nums` / `font-mono`) для дедлайнов и дат смен.
  - Никаких визуальных перегрузок: чистые текстовые метаданные с деликатными точечными разделителями (`·`).
  - Микроанимации при переключении фильтров групп и смене статусов.

## 3. Key Product Decisions & Trade-Offs

- **Решение 1: Сквозная синхронизация КПП с задачами (Tasks) в Firestore**:
  - *Выбранный подход*: Каждый этап КПП для группы является полноценным документом в коллекции `tasks`, что сохраняет единый источник правды и моментально обновляет прогресс в личных кабинетах участников.
  - *Почему*: Это гарантирует, что изменения, сделанные куратором в КПП, мгновенно видят все участники через `onSnapshot`.
- **Решение 2: Сохранение гибкого кастинга актёров**:
  - *Выбранный подход*: Актёры остаются в резерве, но в этапе КПП «Кастинг» появляется удобное окно быстрого приглашения актёра на смену без разрушения структуры групп.
  - *Почему*: Полностью соответствует указанию пользователя «пока не трогать актёров», но даёт группам готовый инструмент для проб.

## 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────┐
│                   App.tsx (Main Hub)                   │
├──────────────────────────┬─────────────────────────────┤
│   GroupBoard (Teams)     │  MasterScheduleView (КПП)   │
│  - 5 Съёмочных групп     │  - Таймлайн 4 этапов пилота │
│  - Резерв (34 чел)       │  - Прогресс-бары готовности │
│  - Корзина (12 чел)      │  - Контроль дедлайнов       │
└────────────┬─────────────┴──────────────┬──────────────┘
             │                            │
             ▼                            ▼
┌────────────────────────────────────────────────────────┐
│               Firestore Cloud State                     │
│  /groups (5 групп: grp-1, grp-2, grp-3, grp-6, grp-7)  │
│  /tasks (КПП задачи с дедлайнами и стадиями сдачи)    │
│  /cinelab_backups (Точки восстановления)               │
└────────────────────────────────────────────────────────┘
```

- **Сущности данных**:
  - `FilmGroup`: обновляется статус `stage` (`development` | `pre_production` | `production` | `post_production` | `completed`).
  - `Task`: поля `groupId`, `stage`, `deadline`, `status` (`todo` | `in_progress` | `review` | `completed`), `assignedToId`.
- **Отказоустойчивость**:
  - Автоматическая валидация дат и статусов.
  - Сохранение снимка базы в `cinelab_backups` при массовом обновлении дедлайнов.
