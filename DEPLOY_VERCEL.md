# 🚀 Пошаговая инструкция по развёртыванию на Vercel

Приложение **Кинолаборатория** полностью настроено и оптимизировано для мгновенного развёртывания на бесплатном хостинге **Vercel**.

---

## Вариант 1. Развёртывание через GitHub (Рекомендуемый, 3 минуты)

### Шаг 1. Создание репозитория на GitHub
1. Зайдите на [github.com](https://github.com) под своим аккаунтом.
2. Нажмите зелёную кнопку **«New»** (Создать новый репозиторий).
3. Назовите его, например, `cinema-lab-planner` (тип репозитория можно выбрать *Public* или *Private*).
4. Выполните в папке проекта:
   ```bash
   git init
   git add .
   git commit -m "Кинолаборатория: система съёмочных групп, роли и медиатека"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/cinema-lab-planner.git
   git push -u origin main
   ```

### Шаг 2. Импорт в Vercel
1. Перейдите на [vercel.com](https://vercel.com) и войдите через GitHub в 1 клик.
2. Нажмите кнопку **«Add New...»** → **«Project»**.
3. В списке репозиториев найдите `cinema-lab-planner` и нажмите **«Import»**.
4. В поле настроек Vercel уже автоматически подставит:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. *(Опционально)* Если вы хотите общую базу данных Firebase в реальном времени, раскройте блок **Environment Variables** и вставьте значения из `.env.example`. Если оставить пустым, приложение работает автономно с сохранением данных в браузере.
6. Нажмите кнопку **«Deploy»**.

### Шаг 3. Готово!
* Через 40–60 секунд проект будет опубликован по ссылке вида:
  `https://cinema-lab-planner.vercel.app`
* Эту ссылку можно отправить коллеге-продюсеру и сохранить на мобильный телефон.

## Вариант 2. Развёртывание через Vercel CLI (через терминал за 1 минуту)

Если у вас установлен Node.js и npm:
```bash
# 1. Установите CLI
npm i -g vercel

# 2. Выполните команду в папке проекта
vercel

# 3. Нажмите Enter на все стандартные вопросы
# 4. Для продакшн сборки:
vercel --prod
```

## 👥 Как дать доступ коллеге-продюсеру:

1. **Отправьте ему постоянную ссылку:**
   `https://ваше-приложение.vercel.app`
2. **Как работать в разных ролях:**
   - **Продюсер / Администратор:** имеет полный доступ к перемещению участников, авто-балансировке, удалению стоп-листов, медиатеке и просмотру закрытого **«Журнала аудита»**.
   - **Участник / Студент:** при переключении роли в верхнем меню участник видит только свой личный кабинет (задачи, VK, пожелания) и может **только просматривать** все 7 съёмочных групп без возможности двигать карточки.
   - **Прямая ссылка для конкретного участника:**
     Вы можете отправить участнику ссылку с параметром `?member=CINE-01` или `?member=Ксения`, и система сразу откроет его личный кабинет.
